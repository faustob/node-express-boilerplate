**Outstanding (2):**
- ⚠ qr-metric-naming (`src/config/tracing.js`): The new histogram `http.server.request.duration.business` records milliseconds but is declared with unit 'ms', while OTel semconv style for HTTP server request duration is seconds; the name also appends implementation-detail-like suffix `.business` rather than stating what is measured, and duplicates the concept the auto-instrumentation already emits as `http.server.request.duration`. — _Rename to a semconv-shaped name (e.g. http.server.request.duration with a tenant.tier attribute) or drop the redundant manual histogram, and if kept record in seconds to match semconv unit style._
- ⚠ qr-not-a-noop (`src/config/tracing.js`): The defensive try/catch around sdk.start() treats a failed second registration as 'use existing provider', but if sdk.start() itself throws the NodeSDK is not started and its MeterProvider/TracerProvider is never installed globally; the module-level meter/counter/histogram created afterward would then bind to whatever global exists (possibly the Noop if no agent registered), silently emitting nothing. — _Do not swallow sdk.start() failures as success; only guard against a genuine already-registered global, and construct instruments lazily on first use so they bind after the provider is confirmed registered._
